# Machine Learning Module

Цей модуль містить пайплайн підготовки даних, навчання та валідації моделі класифікації хвороб рослин.

## Структура
- `src/` — вихідний код (`dataset.py`, `train.py`, `evaluate.py`)
- `reports/` — звіти з аналізу даних та метрик моделей
- `data/` — локальні дані датасету (в `.gitignore`)
- `runs/` — збережені чекпойнти та логи експериментів (в `.gitignore`)
